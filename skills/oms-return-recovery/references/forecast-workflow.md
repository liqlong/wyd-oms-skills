# 退件预报工作流程

创建预报时读取本文件；字段及状态口径同时参考 [退件操作说明](return-operations.md)。

## 退件预报创建和查询

用户要求创建预报时，先查看 `create_oms_return_forecast` 的实时参数定义。
收集客户可用退件仓库、物流服务商、跟踪号、参考号以及1至25条SKU和正整数数量。
参考号在此接口必填，缺失时要求补充，不套用普通入库参考号可省略的规则，不自动生成。
预计到货日期可省略；`operateInstruct` 未指定时不传，不默认产品检查或销毁。
用户明确指定销毁时说明该预报包含销毁指令，确认用户确实同意后执行；不凭货值或货物质量替用户选择。

展示拟创建的仓库、跟踪号、参考号、SKU数量、预计日期及所选指令，明确授权后调用
`create_oms_return_forecast(request, confirmed: true)`；已有具体授权时不重复询问。
服务端分别按参考号和跟踪号核对已有预报，`EXISTS` 时展示已有单据并停止创建，由用户决定下一步。
不自动改号、作废、复用或再次创建；用户提供新的资料后按其新指令处理。
成功回执 `data.rwcForecastNo` 是预报单号，不是招领退件单号。

使用 `inbound_return_forecast_query_page` 按预报单号、参考号或跟踪号查询入仓情况，参数先查看定义。
`UNKNOWN` 先按参考号和跟踪号核实，不自动重建；未查到也不能认定上次创建失败。
